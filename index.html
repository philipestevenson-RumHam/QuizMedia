💡 Pro Tips

Pass Button: Skip a question without penalty (always gives 0 points). Have a guess on Ladder questions though.
Time Expired: If timer runs out, treated same as Pass (0 points, doesn't trigger Wipeout, but have a guess on Ladder questions./Ladder reset).

🎯 Question Types

⌨️ Keypad

Click the first letter from the grid.

🎲 Keypad Scrambled

Click the first letter from the grid - Unfortunately the grid is in a random order.

📸 Multiple Choice

Pick one answer. Red = wrong, green = right.

✅ Select Multiple

Select ALL correct answers.

🔔 Sort It Out

Click options in the correct order.

🔔 Sort It Out (Partial)

Click options in the correct order. Slightly nicer.

⬆️⬇️ High Brow - Low Brow

A harder question followed by an easier alternative half way.

⚠️ Impossible

Three choices: One gives full points, one gives zero, one gives negative points!

🔢 Number

Enter the exact number only.

✍️ Text

Type the full answer. Spelling counts!

🔤 First Letter Text

Type the first letter (ignore "The"/"A").

🎯 Pointfull

Type your answer from the options. Better answers = bonus points!

🎯 Eliminator

Options disappear over time. One correct and one wrong remain at the end!

🔢 Scoring Methods

🔢 Timer

Faster = more points! Score decreases as time runs out. Correct answers only.

🔢💀 Timer (Evil)

Same as Timer, but wrong answers = negative points!

📈 Ladder

Points accumulate for each correct answer. One wrong answer resets the ladder to zero!

💥 Wipeout

One wrong answer = entire round becomes 0! Passes/timeouts don't count as wrong.

🎯 Fixed

Full points if correct, zero if wrong. Time doesn't matter.

🎯💀 Fixed (Evil)

Full points if correct, negative points if wrong!
